# Taco Labs Express Boca – Shopify theme

Theme for **boca.tacolabsfl.com**. The repo root is the Shopify theme (layout, sections, snippets, templates, assets, config, locales), so it can be connected directly with Shopify's GitHub integration.

## Connect to Shopify
Online Store → Themes → Add theme → **Connect from GitHub** → pick this repo and the `main` branch. Every push to `main` updates the connected theme, and edits made in the theme editor are committed back to the branch.

## Store setup (once)
1. Products → Import → `setup/taco-labs-express-products.csv`
2. Create 6 pages titled exactly Menu, Deals, About, Contact, FAQ, Allergens on the Default page template (the theme picks the right sections per page). Copy for 4 of them is in `setup/pages/`.
3. Publish the theme.

Full instructions: `setup/SETUP-GUIDE.md`. Every link on the site: `setup/LINK-CHECK.md`. Sign-up pop-up plan (later): `setup/POPUP-SETUP.md`.
